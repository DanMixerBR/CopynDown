# **CopynDown**

Developed by **DanMixerBR**
<br> </br>
CopynDown is a robust Python-based solution for downloading media from several platforms. Featuring a lightweight and efficient interface, the app allows you to download videos and audios with just a few clicks.
<br> </br>

Powered by:
<br>
**Python**
<br>
**CustomTkinter**
<br>
**yt-dlp core**
<br>
**Deno Runtime**
<br>
**FFmpeg Essentials**
<br> </br>

**Important note:** For subtitles to be recognized by TVs and other devices, the subtitle file must have the same name as the video and be saved in the same location.
<br> </br>

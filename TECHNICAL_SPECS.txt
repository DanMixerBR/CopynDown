========================================================================
                 COPYNDOWN - TECHNICAL SPECIFICATIONS
========================================================================
Version: 2.6.0
Engines: yt-dlp, FFmpeg
========================================================================

This document outlines the default parameters, codecs, and arguments 
used by CopynDown's engines for downloading and converting media.

------------------------------------------------------------------------
1. YT-DLP ENGINE (DOWNLOADS)
------------------------------------------------------------------------

[GLOBAL ARGUMENTS]
- Ignore errors: -i
- Output Template (Social Media*): %(uploader)s [%(id)s].%(ext)s
- Output Template (Standard): %(title)s.%(ext)s
* Social media includes Instagram, TikTok, Kwai, Twitter/X, Facebook, Reddit, LinkedIn, Pinterest, and Snapchat.

[VIDEO DOWNLOAD ARGUMENTS]
- Embed Thumbnail: --embed-thumbnail (Except for WEBM)
- Embed Metadata: --embed-metadata
- Embed Subtitles: --write-subs --write-auto-subs --sub-langs [lang] --convert-subs srt --embed-subs

[VIDEO FORMAT SELECTION (-S)]
- MP4 Target:  res:[Y],aext:m4a
- MKV Target:  res:[Y],aext:opus
- WEBM Target: res:[Y],vcodec:vp9,aext:opus
- 1080p H.264: res:1080,vcodec:avc1,aext:m4a
- Remuxing:    --merge-output-format [EXT] --remux-video [EXT]
*(Where [Y] is the selected resolution: 360, 480, 720, 1080, 1440, 2160)*

[AUDIO DOWNLOAD ARGUMENTS]
- Extract Audio: -x
- Audio Format:  --audio-format [EXT]
- Quality (128k/192k/320k): --audio-quality [BITRATE]
- Embed Thumbnail: --embed-thumbnail (Except for WAV)
- Embed Metadata:  --embed-metadata --parse-metadata "%(playlist_index|)s:%(track_number)s" (Except for WAV)


------------------------------------------------------------------------
2. FFMPEG ENGINE (CONVERSIONS)
------------------------------------------------------------------------

[GLOBAL ARGUMENTS]
- Overwrite existing: -y
- Input: -i [SOURCE]

[VIDEO CODECS (-c:v)]
- H.264: libx264    | Params: -crf 18 -preset faster -pix_fmt yuv420p
- H.265: libx265    | Params: -crf 22 -preset faster -tag:v hvc1
- VP9:   libvpx-vp9 | Params: -crf 20 -b:v 0 -row-mt 1 -cpu-used 4
- Copy:  copy       | (No re-encoding)
- None:  -vn        | (Drops video stream)

[AUDIO CODECS (-c:a)]
- AAC:   aac          | Params: -b:a 192k (CBR)
- MP3:   libmp3lame   | Params: -q:a 2 (VBR - Transparent Quality)
- Opus:  libopus      | Params: -b:a 192k (CBR)
- Ogg:   libvorbis    | Params: -q:a 2 (VBR - Transparent Quality)
- FLAC:  flac         | (Lossless, no bitrate specified)
- WAV:   pcm_s16le    | (Uncompressed)
- Copy:  copy         | (No re-encoding)
- None:  -an          | (Drops audio stream)

[AUDIO MODIFIERS]
- Channels (-ac): 2 (Stereo) or 1 (Mono)
- Sample Rate (-ar): 48000 or 44100


------------------------------------------------------------------------
3. INTELLIGENT AUTO-FIXES (COMPATIBILITY SAFEGUARDS)
------------------------------------------------------------------------
To prevent conversion failures and ensure playback compatibility across 
all devices, CopynDown applies the following automatic overwrites:

# HDR Handling (10-bit vs 8-bit SDR)
- H.264: Strictly locked to 8-bit SDR (-pix_fmt yuv420p). If a user converts an HDR video using H.264, it will automatically tone-map to standard colors to guarantee playback on legacy devices.
- H.265 and VP9: Dynamically adapt to the source. If the input is HDR (10-bit), the output will preserve the HDR metadata natively.

# Resolution Scaling
- FFmpeg cannot scale resolutions using the 'Copy' codec. If the user requests a resolution change while 'Original' is selected, CopynDown forces 'libx264' (or 'libvpx-vp9' for WEBM) to ensure the resize operation succeeds without crashing.

# AVI Compatibility Lock
- If target is AVI and Video Codec is 'Copy' or 'VP9' -> Forces 'libx264'
- If target is AVI and Audio Codec is incompatible (AAC/FLAC/Opus/Copy) -> Forces 'libmp3lame'

# WEBM Compatibility Lock
- If target is WEBM and Video Codec is H.264/H.265/Copy -> Forces 'libvpx-vp9'
- If target is WEBM and Audio Codec is AAC/MP3/FLAC/Copy -> Forces 'libopus'
- If user attempts to download WEBM format with '1080p (H.264)' -> Forces '1080p (AV1/VP9)'

# MP4 & MOV Compatibility Lock
- If target is MP4/MOV and Video Codec is 'VP9' -> Forces 'libx264'
- If target is MP4/MOV and Audio Codec is 'Opus' -> Forces 'AAC'
- Safe Copy: If source is WEBM/MKV/OGG and user attempts to 'Copy' into MP4/MOV -> Forces H.264/AAC re-encoding to prevent container corruption.

# Extract Original Audio Lock
- If user extracts pure audio into MP3 or Ogg container -> Forces re-encoding to VBR (-q:a 2)
- If user extracts pure audio into WAV container -> Forces re-encoding to pcm_s16le
- If user extracts pure audio into M4A container -> Safely 'Copies' ONLY if source is MP4/M4A/AAC.
Otherwise, forces AAC re-encoding (-b:a 192k).
*(Pure copy into strict containers from random sources often breaks headers).*
